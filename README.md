
# Rota Financeira

Aplicação web progressiva (PWA) desenvolvida para
auxiliar motoristas no controle de suas finanças.

## Funcionalidades

- Registro de receitas e despesas
- Controle de lucro líquido
- Histórico de transações
- Metas financeiras
- Relatórios e gráficos
- Autenticação de usuários
- Armazenamento em nuvem

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL
- Progressive Web App (PWA)

## Como executar

1. Clone o repositório.
2. Configure as credenciais do Supabase no config.js.
3. Execute o projeto com o Live Server.
4. Acesse pelo navegador.
